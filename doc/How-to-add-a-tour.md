# How to Add a New Tour in KystSti

Follow this guide to add a new tour to the app using the exported `.ts` file from the TourBuilder:

## 1. Export the Tour from TourBuilder
- Go to the "Export" tab in the TourBuilder.
- Download or copy the generated `.ts` file for your tour.

## 2. Place the File in the Correct Folder
- Put the exported `.ts` file in:
  
  `src/data/tours/`


## 3. Check That Everything Works
- Restart the app if needed.
- Your new tour should now appear in the app.

---

**Tips:**
- Make sure all image URLs and audio files are accessible.
- Test the tour in the app to ensure everything looks correct.
